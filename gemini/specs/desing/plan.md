# Frontend Refactor Plan - The Silent Navigator

This document details the frontend refactor towards Material Design 3 and MVC architectural pattern.

1. **Architecture**: Separate components into `index.jsx`, `View.jsx`, `api.js`, `styles.js`.
2. **Styling**: Replace Tailwind with MUI, following "The Silent Navigator" guidelines.
3. **Localization**: Move all text into `src/locales/texts.json` grouped by page.
4. **Mocking**: Add a mock testing setup with a toggle and a guide.

This plan was approved and execution has started.
