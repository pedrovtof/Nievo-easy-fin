
# 1.0 Cache

A pasta `AI/Cache/` está no `.gitignore` e **NÃO sobe para o GitHub**.

Use essa pasta sempre que possível para criar um historico interno.

Sempre crie um arquivo de plano de ação para validação, voce deverá questionar se o analista está de acordo com a ação do arquivo.

Gere arquivos no final de toda a etapa dentro dessa pasta para explicar o que foi editado.

Para cada etapa realizada voce deverá escrever em um arquivo dentro da pasta de cache, sempre confira o arquivo quando for para a etapa seguinte.

Voce usára um agent em segundo plano com modelo flash para criar e ler esses arquivos temporarios para contexto

# Commit

Sempre pergunte se pode realizar o commit como ultima etapa antes de encerrar a conversa.
